# 🤝 Doações e colaboração

As chamadas e orientações da home são editadas em **Conteúdo da Landing Page → Doações**. Os dados financeiros são separados, para não ficarem no código nem se misturarem aos textos.

- **Conteúdo do site → Doações · PIX e dados bancários**: editar chaves PIX, QR Code, banco, agência, conta e favorecido.
- **Conteúdo da Landing Page → Doações**: editar títulos, textos, imagens editoriais e chamadas.
- **Conteúdo da Landing Page → Conteúdos complementares**: consultar blocos antigos migrados (por exemplo produtos para arrecadação).

A página antiga `/colabore` não é necessária como catálogo separado. Consulte o [guia de migração](./migrar-conteudo-legado.md).
