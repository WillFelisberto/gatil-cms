# 💙 Apadrinhamento na landing

A seção principal de apadrinhamento é editada em **Conteúdo do site → Conteúdo da Landing Page → História e apadrinhamento**.

As imagens e descrições dos gatos continuam na collection `cats`. Habilite **Disponível para apadrinhamento** no cadastro do gato para mostrar a ação no card único da landing. Os blocos antigos podem ser importados para **Conteúdos complementares** sem duplicação, conforme [o guia de migração](./migrar-conteudo-legado.md).
